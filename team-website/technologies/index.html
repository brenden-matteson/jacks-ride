Technologies

Languages

    HTML, CSS, JavaScript

  • When creating a website, we need to have 3 basic languages to back up the website. HTML will be used to create layouts of the website, like the homepage, profiles, direct messaging rooms between students, post from students, etc. CSS will help stylize the webpage to make it an easy process to move around the website. JavaScript will help us create functions that will reduce workload on coding.

    • SQL

  • SQL is used in conjunction with the database component of JacksRide, we will need to use SQL to manage, query, and manipulate the data stored on our database. Post information and account information are a few key data that we need to use SQL for.

Frameworks

    Express Node.js Framework

  • The Express back-end framework will be useful for maintaining RESTful api architecture. It will help us simplify client requests and leverage middleware to process requests such as user authentication. It will also provide the option of using partials that will make keeping our project streamlined easy. The Express framework is also stateless by default, meaning we will not be tracking user data.

    • PostgreSQL

  • PostgreSQL is a free, open-source relational database management system that we will use mainly for testing purposes to make sure that our platform behaves as expected when querying databases. Post information and account information are a few key data that we need to store in a database.

    • NAU CAS

  • NAU CAS is the login portal that all NAU students use when interacting with any NAU affiliated websites/software. Since we want our users to be verified NAU students, including NAU CAS within our system is a big benefit. Students will use the portal to login to the website. After verification, students will be allowed to create an account to find/create rides.

Tools

    Visual Studio Code

  • Visual Studio Code is a programming IDE that we used to develop in, we can sync it with our GitHub repository to make branching and committing easy. It also has many built in tools that will allow us to test out each web element locally when developing.

    • GitHub

  • GitHub allows us to store, manage, share, and collaborate on the same codebase. We will use it as a back-up for our code and will serve as our version control for pushing releases and as a way to revert our codebase in the event that something breaks.
